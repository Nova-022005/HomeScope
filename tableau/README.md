# Tableau Directory

This directory contains Tableau workbooks, dashboards, and visualizations.

## Structure

### `/dashboards`
Store your Tableau dashboard files (.twb or .twbx) here.

**Expected Dashboards:**
- Main interactive dashboard
- Scenario-specific dashboards
- Performance testing dashboards

### `/visualizations`
Store individual visualization exports (images, PDFs) here.

**Expected Visualizations:**
1. Overall Data Overview
2. Total Sales by Years Since Renovation
3. Distribution of House Age by Renovation Status
4. House Age Distribution by Number of Bathrooms, Bedrooms, and Floors

## File Naming Convention
- Dashboards: `HomeScope_Dashboard_[Name].twbx`
- Visualizations: `Scenario[#]_[Description].png`
