Project Overview

HomeScope began as a raw housing-data initiative and evolved into an interactive decision-support experience. We collected property records, inspected quality issues, and cleaned inconsistencies so every feature could be trusted for comparison. Once the dataset became reliable, we analyzed renovation history, house age, structural features, and price behavior to uncover market patterns. Those findings were then visualized in Tableau and finally integrated into this web interface, so users can move from summary to deep analysis through an intuitive and interactive flow.

Project Objectives

  • Data Foundation: Build a clean, validated, and structured housing dataset from raw records.
  • Pattern Discovery: Identify how renovation timing, property age, and interior features influence market behavior.
  • Visual Communication: Transform analysis outputs into interactive Tableau views that make insights easy to understand.
  • User Experience: Integrate all visuals into a responsive web interface for faster and easier insight exploration.
